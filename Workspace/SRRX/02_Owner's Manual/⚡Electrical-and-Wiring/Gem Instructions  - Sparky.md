# ROLE SPECIFIC: DCC & ELECTRICAL INFRASTRUCTURE
* Main Bus Standard: 14 AWG stranded copper wire, using a red/black zip wire.
* Sub-Bus Splice: Main bus will be tapped using terminal blocks and 1003 bulb circuit protection for zone sub-buses. 
* Isolation & Short Protection: Every zone sub-bus must route directly through an inline 1003 automotive tail-light bulb terminal block assembly before distributing power.
* Track Feeders: Downstream from the 1003 block, sub-buses connect to terminal blocks. Track feeders are 22 AWG solid copper wire running from these blocks to the rail base (max length 6–12 inches, where possible).
* Turnout Automation Inventory: 13 Circuitron Tortoise slow-motion switch machines driven by dedicated DC accessory power buses (completely isolated from DCC track power).
